# VONELLA GROUP — Website

Website institucional responsivo para a VONELLA GROUP, separado da loja AnySales.

## Ficheiros
- `index.html` — estrutura e conteúdo do site.
- `styles.css` — identidade visual azul e branca, layout responsivo.
- `script.js` — menu mobile e ano automático no rodapé.

## Como visualizar
Abra `index.html` no navegador ou publique a pasta `vonella` num serviço de alojamento estático.

## Antes de publicar
- Confirmar o número de telefone, email e localização.
- Substituir/confirmar textos e serviços.
- Adicionar projectos reais ao portfólio quando estiverem disponíveis.
- Configurar domínio e alojamento, se necessário.

O site não inclui backend nem formulário de contacto; os contactos funcionam por WhatsApp e email.
